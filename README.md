# PRDA-04 — Job Market Analysis

## 📌 Project Overview

This project analyzes 742 Data Science job postings with 42 features to identify job demand, salary patterns, hiring companies, industries, technical skills, education requirements, and seniority patterns.

## 🎯 Objectives

- Analyze job demand across locations
- Compare salary patterns
- Identify leading industries and companies
- Analyze popular job titles
- Identify in-demand technical skills
- Study education and seniority patterns
- Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies

- MySQL
- Python
- Pandas
- Power BI
- Excel/CSV

## 📊 Dataset

- Records: 742
- Features: 42
- Domain: Data Science Job Market
- Salary Unit: Thousands of US Dollars ($K)

## 📈 Key Insights

- California (CA) has the highest number of job postings with 152 postings.
- Python is required in 392 job postings.
- Excel is required in 388 job postings.
- SQL is required in 380 job postings.
- AWS is required in 176 job postings.
- Spark is required in 167 job postings.
